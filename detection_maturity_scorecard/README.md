# Detection Maturity Scorecard

Scores an entire detection program against the full MITRE ATT&CK matrix: maps deployed rules to tactics/techniques, computes coverage percentage per kill-chain phase, evaluates data source health (log availability, retention, latency), and produces an ATT&CK Navigator-style heatmap plus a prioritized roadmap for closing the biggest gaps — program-level ownership, not single-detection thinking.

```bash
python main.py
```
